# v0.1.2 — AnkiConnect note type validation

- Reject conflicting field and card-template names during preview, before
  sending a write to AnkiConnect. For example, `front` can no longer be added
  beside `Front`.
- Apply the same name comparison when adding, renaming, creating, or cloning
  note type structures, including Unicode-equivalent names. Case-only renames
  of the same field or template are still allowed.

No MCP configuration changes are required. Tested with Anki Desktop 26.09.4
and the November 20 AnkiConnect update in both `v1` and `legacy` modes.
