# v0.1.0 — Initial release

Draft for the upcoming GitHub Release.

Anki MCP connects a local AI chat client to Anki Desktop through AnkiConnect.
This first release provides 73 tools over stdio.

## Highlights

- Search, create, edit, tag, convert, and delete notes.
- Manage decks and shared deck presets; inspect card scheduling and review history.
- Create and customize note types, fields, card templates, and shared CSS.
- Preview existing cards as HTML/CSS documents without opening a browser.
- Store and attach media, inspect references, and review deletion impact.
- Import and export local `.apkg` deck packages.
- Read collection statistics, sync, check the database, and request Undo.
- Track collection operations and request supported cancellation.

## Getting started

Requires Node.js 24 or newer, an MCP client supporting local stdio servers,
and Anki Desktop running with AnkiConnect. Set `ANKI_API_MODE=v1` for the
full tool set; legacy mode supports a subset for older add-ons.

The npm package is `@ryhus/anki-mcp@0.1.0`.
See the [README](../../README.md) for setup and example prompts.

## Before making changes

Review previews and required confirmations before applying destructive changes.
Not every mutation offers a preview. There are no automatic backups, write
retries, or rollback; after an error, inspect Anki before repeating an action.
Cancellation requests do not undo changes already made.
